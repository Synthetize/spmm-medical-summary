# Ísland.is Medical Summary

A concept and prototype for an extension of the [Ísland.is](https://island.is) app that lets Icelandic citizens and residents create, translate and carry a medical summary when travelling abroad.

Course project for **T-740-SPMM Software Project Management** at Reykjavik University (Fall 2025), carried out with stakeholders from Stafrænt Ísland (Digital Iceland).

## The problem

Icelandic travellers have no standardized, secure way to bring their medical information abroad. They rely on printed documents, doctor's notes or MedicAlert IDs, if they prepared anything at all. Foreign clinicians then lose time, repeat tests, or treat without knowing allergies, medications and prior conditions.

## The idea

A Medical Summary feature inside the Ísland.is app, where the traveller can:

- **Create** a summary from their health records
- **Choose** which medical information to include
- **Translate** it into the language of the destination country
- **Export** it as a PDF, or add it to the in-app wallet with a QR code and an expiry date

Long-term goal: *better medical treatment outside Iceland, so that travellers feel secure, relieved and in control.*

## What is in this repository

The project is a project-management and UX exercise, not a software implementation. The deliverable is a set of five reports and a Figma prototype.

| Phase | Report | Content |
|---|---|---|
| A | The Team | Team members, skills (contribution map), meeting schedule, team rules |
| B | Discovery | As-is analysis, user journey mapping, user group analysis, stakeholder meeting, 5 user interviews, UX goals |
| C | Project Proposal | Goal, strategy and value, stakeholder analysis and registry, scope, product backlog (45 user stories), risk analysis, resources and cost estimate |
| D | Portfolio Analysis | Portfolio strategy and a weighted prioritization model applied to four competing project proposals |
| Final | Prototype and User Testing | Sprint planning (12 sprints), Figma prototype, happy paths, 5 usability tests, second stakeholder meeting, next steps |

## Method

- **UCD Sprint** templates for user group analysis, mapping and UX goals
- **Agile / Scrum** with two-week sprints, tracked on Trello
- **Figma** for the interactive prototype, styled after the existing Ísland.is design
- Semi-structured interviews and think-aloud usability testing

## Key results

- **UX goals:** security, relief, control
- **MVP (Sprint 1):** create a summary, choose its contents, change its language
- **Usability testing:** all five participants completed the main tasks and saw clear value in the feature. Recurring issues were the "Export" label, the placement of the "Create Medical Summary" button, and the inability to view or edit an existing summary
- **Stakeholder feedback:** add "Select All", require authentication before accessing health data, consider offline caching and passkeys
- **Estimate for full development:** 1.5 to 2 years, 75 to 100 man-months
- **Recommendation:** continue development, with a second testing round that includes practising doctors
